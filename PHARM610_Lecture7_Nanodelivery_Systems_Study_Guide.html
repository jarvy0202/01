1. Cyclodextrins

  • Cyclic glucose oligomers: α = 6, β = 7, γ = 8 units. Hydrophilic outside, hydrophobic cavity inside.
  • Drug enters cavity → inclusion complex (1:1 or 1:2) → solubilizer.
  • Not useful for targeting: drug is released too fast.

2. Liposomes

Structure

  • Phospholipid bilayer vesicles.
    • Hydrophilic drug → aqueous core
    • Hydrophobic drug → bilayer
    • Amphiphilic drug → interface
  • Phospholipids: PC, PE, PS, PI, PG.
    • Fatty acid chains → transition temperature (Tm).
    • Cationic/ionizable heads → membrane fusion, endosomal escape, RNA loading.
  • Cholesterol → ↑ rigidity, ↓ drug leakage.

Preparation

  1. Thin-film hydration (old method): lipid in chloroform → rotary evaporation → thin film → hydrate with buffer → large MLVs → sonication / extrusion to make them smaller and uniform.
  2. Ethanol injection: lipid in ethanol injected into water → smaller, more uniform; usually no extrusion needed.
  3. Microfluidics: better mixing; automated and scalable.
  • Vesicle types: SUV, LUV, MLV, MVV (multivesicular).
  • Designs: conventional, pH-sensitive, cationic, thermo-responsive, immuno- (antibody), stealth/long-circulating (PEG).

Drug loading

  • Passive: drug added during preparation (organic or aqueous phase).
  • Active / remote: liposome formed first, then incubated with drug; a pH gradient or salt inside pulls the drug in.
    • Doxil: ammonium sulfate gradient → doxorubicin precipitates inside → very low leakage.

Quality criteria for generic liposomes (e.g., generic Doxil)

  • Lipid content · Drug encapsulation · Size, PDI, charge · Stability (aggregation, shelf life) · Drug release

Other tools

  • AF4 (field-flow fractionation): separates by size (or charge/density) using flow only — no stationary phase.
  • In vitro release: dialysis (can be run in USP apparatus 2); add surfactant or albumin to keep sink conditions for poorly soluble drugs.

★ 3. Release Rate → PK → Targeting

FormulationDrug locationDrug PK
Rapid release (e.g., Visudyne)In the bilayer≈ free drug
Sustained releaseIn the aqueous core≈ carrier
Fast release → PK = free drugIn betweenSlow release → PK = carrier
The slower the release, the more the drug follows the carrier. Slow release is a prerequisite for targeting.
  • Sustained release → effective dose ↓, toxic dose ↑ → therapeutic index ↑.
  • Accumulation in tumors / inflammation via EPR.

★ 4. Conventional vs Stealth Liposomes

ConventionalStealth (PEG)
ExamplesMyocet (doxorubicin), AmBisome (amphotericin B)Doxil / Caelyx
MechanismOpsonins adsorb → taken up by MPS / Kupffer cellsPEG hydration layer blocks protein adsorption → not recognized by MPS
ResultShort circulation, high liver/spleen uptake, toxicity with repeat dosesLong circulation; + sustained release → drug reaches tumors / inflammation
  • AmBisome (1997, SUV, amphiphilic drug at interface) → ↓ nephrotoxicity.

★ 5. Doxil / Caelyx (PEGylated liposomal doxorubicin)

  • ~100 nm · HSPC + cholesterol · t½ > 50 h · main benefit: ↓ cardiotoxicity.
  • PK vs free drug: ↓ CL · ↓ Vd · ↑ t½ · ↑ AUC · ↑ tumor distribution.
  • Vd = Dbody / Cplasma: free doxorubicin 254 L → Doxil 4.1 L (≈ blood volume). Liposomes are too big to leave normal capillaries → drug stays in plasma.
  • Still the best formulation because the precipitated drug barely leaks out.
Side effects ↓Side effects ↑
Cardiac, hematologic toxicity, hair loss, neuropathy, vesicant injury, nausea Mucositis; hand-foot syndrome (PPE) — pressure points squeeze liposomes out of vessels → management: delay next chemo cycle

Onivyde (liposomal irinotecan, 2015)

  • Irinotecan = prodrug of SN-38 (SN-38 ~1000× more potent but poorly soluble). Liposome changes PK the same way as Doxil.

6. Active Targeting & Triggered Release

  • Ligands: antibodies, fragments, nanobodies, aptamers, peptides, folate. Internalizing > non-internalizing.
★ Ligand attachment does NOT increase tumor accumulation (EPR dominates).
  • High ligand density masks PEG stealth → faster clearance.
  • Ligands only change intratumoral distribution.
  • ★ Binding site barrier: in large tumors, liposomes bind the first cell layer and can't penetrate deeper. Micrometastases / vascular targets suit targeted liposomes better.
  • ★ Post-insertion: ligand-PEG-lipid micelles + preformed liposomes → ligand inserts into outer leaflet. Better than pre-mixing because more ligand is exposed on the surface.
  • ThermoDox: lysolipid liposome designed to release at 42 °C; failed because it leaked at 37 °C.

7. Polymeric Nano/Microparticles

  • Natural: gelatin, albumin, alginate. Synthetic: PLA, PGA, PLGA, PCL, PACA.
  • Nanocapsule = drug core + polymer shell (reservoir). Nanosphere = drug dispersed in polymer matrix.

Preparation

MethodKey point
In situ polymerizationFrom monomers (emulsion / interfacial); surfactant prevents aggregation
CoacervationMainly microparticles / reservoir; non-solvent → polymer coacervate coats drug core → hardens
Emulsion / solvent evaporationWater-immiscible solvent (chloroform) + PVA; O/W → hydrophobic drug, W/O/W → hydrophilic drug; PLGA
Solvent displacementWater-miscible solvent (acetone, THF); water = non-solvent; smaller particles
Salting outLike displacement, but electrolyte triggers precipitation

Purification (remove free drug)

  • Dialysis — drawback: drug migrates to particle surface → burst release.
  • Ultrafiltration (Amicon) · Ultracentrifugation · SEC/GPC (large particles elute first).
  • Abraxane (albumin-bound paclitaxel, 2005): does not change PK like stealth carriers, but clinically effective.
  • Steric stabilization: hydrophilic polymer on surface prevents aggregation — adsorbed (PVA, Pluronic PEO-PPO-PEO, PEO-PLA) or grafted (PEG).

★ 8. Polymeric Micelles

  • Amphiphilic block copolymers above CMC → core–shell, ~100 nm. PEG shell, hydrophobic core → solubilize / target poorly soluble drugs.
  • Polymers: PEO-b-PPO, PEO-b-PLA, PEO-b-poly(amino acid).

★ Thermodynamics — hydrophobic effect (ΔG = ΔH − TΔS)

  • In water: endothermic (ΔH > 0) → must be entropy-driven.
  • Hydrophobic blocks disrupt water's H-bond network; hiding them in the core restores it → water entropy ↑ → ΔG < 0.
  • In organic solvents: enthalpy-driven.

★ vs surfactant micelles (Cremophor EL, SDS, polysorbate)

  1. Lower CMC (macromolecular hydrophobic block) → stay assembled after dilution in blood.
  2. Kinetic stability: rigid core breaks up over hours vs milliseconds for liquid-like surfactant cores.

→ Allows sustained release & targeting after IV injection.

Drug loading

  • Dialysis (DMSO/DMF vs water) · O/W emulsion (preformed micelles + drug in chloroform, vigorous mixing, evaporate) · Film hydration · Co-solvent evaporation (acetone/ACN/THF) · Microfluidics

  4. Remote loading?Preformed liposome + gradient; Doxil ammonium sulfate → precipitation.
  5. Quality criteria for a generic liposome?Lipid, encapsulation, size/PDI/charge, stability, release.
  6. Why is slow release needed for targeting?Drug PK follows carrier only if release is slow.
  7. Problems with conventional liposomes?MPS uptake, short circulation, liver/spleen toxicity.
  8. How does stealth work?PEG hydration layer → no opsonins → long circulation → EPR.
  9. PK changes with Doxil? Why does Vd drop?↓CL ↓Vd ↑t½ ↑AUC ↑tumor; 254 → 4.1 L, drug confined to blood.
